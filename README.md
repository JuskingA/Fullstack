## 🌐 What Is Full-Stack Development?

Full-stack development involves working with both the frontend and backend of a web application.

### Frontend Development

The frontend is the part of a website or application that users see and interact with.

Common frontend technologies include:

- **HTML** — Structures web pages.
- **CSS** — Styles web pages and controls their layout.
- **JavaScript** — Adds interactivity and dynamic behavior.

### Backend Development

The backend handles the application logic, data processing, authentication, and communication with databases.

Common backend technologies include:

- Node.js
- Express.js
- Python
- PHP
- Java

### Database Development

Databases store, organize, and retrieve application data.

Examples include:

- MySQL
- PostgreSQL
- MongoDB
- SQLite

## 🛠️ Development Tools

The following tools are commonly used in a full-stack development workflow:

- **Visual Studio Code** — Code editor.
- **Git** — Version control system.
- **GitHub** — Platform for hosting and managing code repositories.
- **Web browser** — Used to run and test web applications.
- **Terminal or command prompt** — Used to execute development commands.
